# Démonstration finale — TriFacile

Durée conseillée : 3 à 5 minutes.

1. Présenter le besoin : centraliser les informations de collecte et les bons gestes de tri.
2. Ouvrir l'accueil et présenter les accès rapides.
3. Consulter le calendrier et filtrer par quartier.
4. Ouvrir les points de tri, ajouter un favori puis activer le filtre des favoris.
5. Parcourir les conseils par catégorie.
6. Créer un signalement avec titre, lieu et description.
7. Revenir à la liste, vérifier la présence du signalement puis le supprimer.
8. Expliquer les choix : Flutter, Provider, shared_preferences, données statiques hors ligne.
9. Présenter les tests, les limites et les pistes d'évolution.

À préparer avant la présentation :
- Captures d'écran réelles prises sur émulateur/appareil.
- Exécution réussie de `flutter test`.
- APK produit par `flutter build apk --release`.
- Dépôt GitHub public ou accessible au tuteur.
